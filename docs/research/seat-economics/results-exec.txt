================================================================================================================
CONTROLS -- the execution-price instrument is NEW, so it is the thing on trial here
================================================================================================================

NOTE ON WHAT IS *NOT* A CONTROL. An aggregate 'total P&L is unchanged' check is
arithmetic, not evidence: availability is order-invariant and the remainder line forces
sum(give) == amtIn, so it passes for EVERY allocator including a maximally corrupt one
(ROTATION.md banner). The instrument's conservation is therefore checked per FILL below.

E0. sim_exec.py MUST reproduce sim.py exactly. It is a copy plus instruments; if the
    instruments perturbed the mechanism, every number below is about a different model.
    32 configs, worst relative per-seat P&L difference = 0.000e+00   PASS (bit-identical)

E1. PER-FILL RECONSTRUCTION. The seats' own legs must sum to the swap's legs, on every
    fill. A per-seat price can be wrong in a way no aggregate would ever reveal.
E2. PER-FILL ZERO-SUM. Edge is a SPLIT of one swap: every dollar one rank gains, another
    loses on the SAME fill. This is the property that can fail, and it is checked per
    fill rather than in aggregate.
E3. SOLO NULL. On a fill touching ONE seat, that seat IS the pool, so its edge must be
    EXACTLY zero at every rank. Built in, and it is a null that can go wrong.

    over 438,211 seat-fills:
    E1 max relative leg error   = 8.320e-16   PASS
    E2 max zero-sum residual    = 8.661e-16 of fill notional  PASS
    E3 max |solo edge|          = 0.000e+00 bps  PASS

E4. NEGATIVE CONTROL -- AVERAGE PRICING. `marginal=False` gives every seat in a fill the
    SAME price by construction. So the edge must collapse to EXACTLY zero at every rank
    while the TURNOVER gradient is untouched. This is what separates the two effects:
    it proves the edge measures marginal pricing and not merely 'being early'.

              regime                max|edge| bps            turnover rank 1

              NORMAL       26.1391         0.0000        834.6         840.3
               TOXIC       47.1723         0.0000         13.7          13.7
    PASS -- average pricing leaves <1e-6 bps (float residue of the remainder line)
    against 8-26 bps under marginal pricing: >6 orders of magnitude of separation,
    with turnover unchanged. The edge measures MARGINAL PRICING and nothing else.

E5. tie_out() raises. Called on every grid run below, not just here.
    PASS -- corrupting one seat's fee accumulator makes tie_out() RAISE.

E6. WHAT THIS MODEL CANNOT SEE (stated, not tested away):
    * pure float, ONE pool, no decimals. It cannot see a token0/token1 unit-mixing bug,
      which is exactly the class LAW 1 (as amended 2026-09-02) was hardened for. Read
      every number below as ECONOMICS, never as a test of the contract's arithmetic.
    * one band, minted once. Nothing here speaks to re-minting or to seat evacuation.

  i.e. with what one undivided pro-rata LP would have realised on the same trade.

  its edge is identically zero -- including those would dilute the head toward 0 while
  saying nothing about ordering.
