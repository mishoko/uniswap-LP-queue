6.  (c)  THE CAPITAL-WEIGHTED MEAN IDENTITY -- self-check at every N

  VALUE.md section 1: the N seats share ONE Uniswap position, so their capital-weighted
  mean return IS the return of one ordinary pro-rata LP with the same capital. phi
  creates nothing; it only decides the split.

  WHAT IS AND IS NOT A CONTROL HERE, because LAW 5 asks what could make this read FAIL.
    NOT a control: comparing the capital-weighted mean of d_i/h_i against d.sum()/h.sum()
      within one run. Those are the same division written twice; it cannot fail for any
      implementation of the mechanism. It is arithmetic wearing a control's costume.
    A control: comparing the QUEUE pool's return against a SEPARATE, INDEPENDENTLY
      SIMULATED pro-rata run -- one seat, average pricing, no premium, same seed. That
      one CAN fail, and would, if the queue's availability clamp diverted the price path,
      if premium were created or destroyed rather than moved, or if the held pot were
      silently dropped. It is the second column below.
